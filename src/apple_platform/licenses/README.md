# Bundled license texts

The native library in this package statically links code from
[apple-platform-rs](https://github.com/indygreg/apple-platform-rs):

| Component | License |
| --- | --- |
| apple-codesign, apple-bundles, apple-flat-package, apple-xar, cpio-archive | MPL-2.0 (`MPL-2.0.txt`) |
| apple-dmg, app-store-connect | Apache-2.0 OR MIT |

See the distribution-level `NOTICE` file for source-availability details
required by the MPL.
